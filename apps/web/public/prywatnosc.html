Prywatność w PK Planner

Ostatnia aktualizacja: 7 października 2026 r.

PK Planner nie wymaga konta ani podania imienia czy adresu e-mail i nie używa danych do reklam ani analityki. Ustawienia, własne zajęcia i plan są przechowywane lokalnie na Twoim urządzeniu; strona i API są obsługiwane przez Cloudflare, które może przetwarzać techniczne dane połączenia, takie jak adres IP. Na Androidzie, jeśli włączysz powiadomienia push, aplikacja wysyła do serwera losowy identyfikator instalacji, token powiadomień, ustawienia powiadomień i potrzebne bloki planu, które mogą zawierać nazwy zajęć. Dane rejestracji są przechowywane w Cloudflare i służą wyłącznie do wysyłania wybranych powiadomień; Firebase Cloud Messaging od Google otrzymuje token push i treść wysyłanego powiadomienia. Rejestrację można usunąć, wyłączając powiadomienia w aplikacji, a nieaktywne wpisy są automatycznie usuwane po 180 dniach; przypomnienia na iOS są planowane lokalnie. PK Planner prowadzę osobiście jako SideArker; w sprawach dotyczących prywatności możesz napisać przez GitHub Issues (nie umieszczaj tam danych prywatnych).
